## 좌표(심볼 100×100 칸 기준)

- 심볼 획은 가운데 (50,50), 가장 먼 점까지 반지름 33 — 원형 틀 안전 원(지름 66%) 안.
- **점(녹음·받아쓰기)**: 중심 (50, 50), 반지름 8.5, 빨강 불투명.
- **점(처리 중 — 회의록 만들기·다듬기)**: 같은 중심, 반지름 6.8(=8.5×0.8), 빨강 불투명도 0.6 (그림 파일 값). 움직일 땐 아래 숨쉬기.
- 메뉴 막대 판은 획을 굵힌 한 색 판(`seogi-tray*`), 보이는 범위는 100 칸 중 (16,16)~(84,84).
- 맥 앱 아이콘(`seogi-app*.svg`): 1024 캔버스 안 824 몸통(사방 100 여백, 슈퍼타원 n=5) — 맥 아이콘 격자. 100 칸 심볼을 ×8.24 해서 몸통에 얹음.
- 원형(`seogi-app-round.svg`): 원 가득 바탕 + 심볼 그대로(안전 원 안).
- 안드로이드 적응형: 전경 `seogi-adaptive-fg.svg`(108 칸, 심볼이 가운데 66 안), 배경은 먹 `#191512` 한 색, 단색(테마) 아이콘은 `seogi-mark.svg` 를 한 색으로.

## 상태와 움직임

| 상태                                  | 점                                   | 움직임                                                                                    |
| ------------------------------------- | ------------------------------------ | ----------------------------------------------------------------------------------------- |
| 평소                                  | 없음                                 | —                                                                                         |
| 녹음 중 · 받아쓰기 듣는 중            | 반지름 8.5, 빨강                     | **1.6초** 되풀이: 0–55% 불투명도 1 → 72–88% 0.18 → 100% 1 (ease-in-out)                   |
| 회의록 만드는 중 · 받아쓰기 다듬는 중 | 반지름 8.5 기준 크기 0.72↔0.9, 빨강 | **2.6초** 되풀이 숨쉬기: 0·100% (불투명도 0.35, 크기 0.72) ↔ 50% (0.8, 0.9), ease-in-out |
| 끝남                                  | 사라짐                               | 점이 꺼지고 평소 모양                                                                     |

- 움직임 줄이기 설정이면 멈춘다: 녹음 = 점 불투명 1 고정, 처리 중 = 크기 0.8·불투명도 0.6 고정.
- 맥 Dock 은 실행 중 아이콘을 바꿔 상태를 보인다(`seogi-app-rec` / `seogi-app-busy` 또는 바탕 위에 점 겹치기).
- 맥 메뉴 막대: 평소는 `seogi-tray`(템플릿 — 맥이 밝게/어둡게 바꿈), 녹음 중은 `seogi-tray-rec`(템플릿 아님, 획 검정 + 점 빨강; 어두운 막대에선 획을 흰색으로 바꿔 쓴다).
- 윈도우 작업 표시줄: 겹침 아이콘(오른쪽 아래)으로 `seogi-dot-rec` 를 16px 로.
- 갤럭시 홈 화면 아이콘은 바뀌지 않는다(늘 평소). 알림 줄 작은 아이콘은 흰 한 색(`seogi-mark` 한 색), 펼친 알림 색만 빨강.
