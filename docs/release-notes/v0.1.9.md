# 서기 v0.1.9

0.1.7·0.1.8 에서 생긴 작은 문제들을 고쳤습니다.

## 바뀐 점

- **회의록 만드는 중 점** — 회의록 만들기가 실패한 뒤에도 메뉴 막대와 Dock 의 옅은 점이 꺼지지 않던 문제를 고쳤습니다. 할 일이 없으면 점이 꺼집니다.
- **녹음 중 메뉴 막대 표시** — 밝은 화면에서 메뉴 막대만 어두울 때(어두운 배경 화면) 녹음·회의록 표시의 획이 잘 안 보이던 문제를 고쳤습니다. 이제 메뉴 막대의 밝기를 직접 보고 획 색을 고릅니다.
- **녹음 점 깜빡임** — 녹음을 끝내자마자 다시 시작하면 메뉴 막대의 빨간 점이 깜빡이지 않던 틈을 막았습니다.
- **받아쓴 글 넣기** — 채팅·코드 편집기 같은 앱이나 Numbers·엑셀 칸에서 받아쓴 글이 들어가지 않고 "넣을 곳이 없어요"가 뜨던 문제를 고쳤습니다. 단추·체크 상자·메뉴가 선택돼 있을 때만 복사를 권합니다.
- **받아쓰기 단축키 옮기기** — 처음 판의 기본 키를 ⌥Space 로 옮길 때, 그 키를 이미 서기의 녹음·중요 표시 키로 쓰고 있으면 옮기지 않습니다.
- **뒤로·앞으로** — 휴지통으로 보낸 회의는 뒤로·앞으로 가기에서 건너뜁니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.9_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.1 이후 판을 쓰고 있다면 앱 위쪽의 "설치"로 바로 바뀝니다. 바꾼 뒤 Dock 아이콘이 빈칸으로 보이면 서기를 한 번 끄고 다시 켜 주세요.

**Windows (64비트)** — `Seogi_0.1.9_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
