# 서기 v0.1.14

회의록에서 누가 얼마나 말했는지 보이고, 말한 사람 이름 붙이기가 짧아졌습니다.

## 바뀐 점

- **대화 점유율** — 회의록 위쪽 참석 줄 아래에 누가 얼마나 말했는지 비율 막대가 보입니다. 이름 옆 숫자는 비율이고, 마우스를 올리면 말한 시간이 보입니다.
- **이름 붙이기가 짧아짐** — 말한 사람마다 대표 대사 3개(회의 앞·가운데·뒤에서 하나씩)만 보고 이름을 고르면 됩니다. 한 사람을 정하면 다음 사람으로 넘어갑니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.14_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 처음 열 때 막히면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 이미 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.14_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
