# 서기 v0.1.0 — 미리보기

회의를 녹음하면 받아 적고, 할 일부터 정리한 회의록을 만들어 주는 앱의 첫 미리보기입니다. 직접 써 보면서 고쳐 가는 단계라, 되는 것과 아직 안 되는 것을 아래에 그대로 적습니다.

## 되는 것

- **앱에서 녹음** — 끝내면 받아쓰기와 회의록이 알아서 만들어지고, 다 되면 알림이 한 번 옵니다. 녹음 중에 앱이 꺼져도 그때까지의 녹음은 남습니다.
- **폴더 지켜보기 · 파일 가져오기** — m4a, mp3, wav, aac 등. 같은 녹음은 이름이 달라도 두 번 처리하지 않습니다.
- **화자 구분 받아쓰기** — 내 용어집(이름 · 현장 · 전문 용어)을 녹음의 모든 구간에 씁니다. 화자는 4명까지 구분합니다.
- **회의록** — 한 줄 요약, 할 일(담당 · 기한 · 근거 시각), 결정 사항, 확인 필요. 모든 항목은 녹음의 어느 대목에서 나왔는지 시각이 붙고, 근거가 약한 것은 "확인 필요"로 따로 모읍니다.
- **달력 연동** — 달력의 비공개 iCal 주소를 넣으면 녹음 시각에 맞는 일정의 제목 · 참석자를 가져옵니다.
- **원본 보존** — 원본 녹음은 고치지도 지우지도 않고, SHA-256과 녹음 시각을 `원본정보.json`에 남깁니다.
- **회의록을 쓸 AI 고르기** — 내 컴퓨터(Ollama, 무료) · 내 구독 로그인(Claude · ChatGPT) · 내 API 키.
- **일정 알림** — 일정이 시작할 때 화면 위 작은 창에서 바로 녹음을 시작할 수 있습니다. 회의록이 다 되면 같은 자리에서 알려 줍니다.
- **각자의 구글 드라이브** — 컴퓨터에 있는 드라이브 계정을 찾아 그 안에 녹음함을 만듭니다. 폰으로 녹음한 파일을 거기에 넣으면 회의록이 녹음 옆에 생깁니다.

## 아직 안 되는 것

- 컴퓨터에서 나는 소리(화상 회의 상대 목소리) 함께 녹음
- "이 녹음에 묻기", 회의록 내보내기(Word · PDF), 회의록 틀 고치는 화면
- 5명 이상 화자 구분, 화자 목소리 기억
- 받아쓰기를 외부 AI로 보내기, API 키 보관
- Windows에서의 실제 사용 확인(설치 파일은 만들어지고 실행까지만 확인했습니다)

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.0_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요.

**Windows (64비트)** — `Seogi_0.1.0_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

## 준비물

1. 받아쓰기 모델과 화자 구분 모델(처음 실행할 때 한 번 내려받습니다).
2. 회의록을 쓸 AI 하나.
   - 무료: [Ollama](https://ollama.com/)를 설치하고 `ollama pull gemma3:12b`
   - 또는 로그인된 Claude Code(`claude`)나 Codex(`codex`)

## 정확도

대본을 컴퓨터 목소리로 읽혀 만든 연습용 녹음 8개(3~4분)로 잰 값입니다. 실제 회의에서는 이보다 낮게 나옵니다.

- 글자 오류율: 용어집 없이 2.6 % → 용어집을 쓰면 1.8 %
- 용어집에 넣은 말을 맞게 적은 비율: 77 % → 94 %
- 화자 구분 정확도: 86 % (한 목소리를 변조해 만든 화자라 실제와 다를 수 있습니다)
