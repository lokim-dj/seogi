# 서기 v0.1.11

설정과 회의록을 보기 쉽게 다듬었습니다.

## 바뀐 점

- **설정 분류** — 설정 왼쪽에 회의록 정리 · 녹음 · 받아쓰기 · 보관과 일정 · 시작과 권한 분류가 생겼습니다. 누른 분류의 설정만 보입니다. 창이 좁으면 분류가 위쪽 줄로 바뀝니다.
- **말한 사람 구분** — 받아쓴 글에서 이름 앞에 서기 심볼(기운 타원)이 붙고, 사람마다 다른 차분한 색으로 칠해집니다. 이름을 바꿔도 색은 그대로입니다.
- **다음 일정까지 남은 시간** — "146분 뒤" 대신 "2시간 26분 뒤"처럼 보입니다.
- **윈도우 알림 영역 아이콘** — 어두운 작업 표시줄에서도 서기 아이콘이 보이도록 흰색으로 그립니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.11_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.9 이후 판을 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.11_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
