# 서기 v0.1.1

- 회의록을 쓸 AI 모델을 목록에서 고릅니다. 이름을 적을 필요가 없습니다.
- 맥의 '캘린더' 앱에 넣어 둔 계정의 일정으로 회의 이름을 붙입니다.

## 고친 점

- **모델 고르기** — Claude · ChatGPT(Codex) · 내 컴퓨터 · 내 API 키마다 쓸 수 있는 모델만 목록으로 보이고, 맨 위가 권장입니다. 예전에 손으로 적은 이름은 목록의 모델로 바뀝니다. 고른 모델을 계정에서 쓸 수 없으면 회의록이 실패로 끝나지 않고 그 프로그램의 기본 모델로 씁니다.
- **회의록이 늦는 까닭** — 구독 한도에 걸렸는지, 모델을 쓸 수 없는지 회의함에 쉬운 말로 나옵니다.
- **캘린더** — 맥 캘린더 앱에서 읽을 캘린더를 고를 수 있습니다(처음 한 번 맥이 허락을 묻습니다). iCal 주소는 넣자마자 읽어 보고 "연결됨 · 다음 일정"이나 안 되는 까닭을 보여 줍니다. 처음 켤 때 주소를 붙여 넣고 바로 시작하면 주소가 빠지던 문제를 고쳤습니다.
- **회의함** — 다른 서기(같은 컴퓨터의 다른 판)가 보관 폴더에 만든 회의도 회의함에 나옵니다.
- **새 버전 알림** — 새 버전이 나오면 맨 위 검은 띠에 "설치" 단추가 생깁니다. 누를 때만 받고, 녹음이나 회의록 정리 중에는 끝난 뒤에 설치할 수 있습니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.1_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 앱 안의 "설치" 단추로 받는 업데이트에는 이 창이 다시 뜨지 않습니다.

**Windows (64비트)** — `Seogi_0.1.1_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요. 앱 안의 "설치" 단추로 받는 업데이트는 설치 창이 잠깐 보였다가 서기가 다시 켜집니다.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
