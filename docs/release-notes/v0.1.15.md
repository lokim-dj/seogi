# 서기 v0.1.15

회의록이 확인되지 않은 것을 단정하지 않고, 한 장 요약 카드를 만들 수 있습니다.

## 바뀐 점

- **한 장 요약 카드** — 회의록에서 고객·날짜·참석, 정한 것·숫자, 우리·고객 할 일, 흐름, 말한 몫, 확인 필요를 한 장에 모읍니다. 채팅에 보내기 좋은 그림(PNG)과 A4 PDF 로 회의 폴더에 저장합니다.
- **회의록이 덜 단정함** — 회의가 끝난 뒤의 말, 다른 현장·사례 이야기, 앞뒤가 다른 말에서 나온 항목은 '확인 필요'로 보냅니다. 금액 단위가 이상하거나(예: 1억 5천억) 같은 단가가 두 값으로 나오면 표시합니다.
- **맨 위에 고객·장소** — 회의록과 할 일 복사 맨 위에 고객과 장소가 나옵니다. 녹음이 대화 중간부터 시작됐거나 일정보다 늦게 시작했으면 알려 줍니다.
- **담당은 근거가 있을 때만 이름으로** — "제가 보낼게요"처럼 말한 사람이 스스로 맡은 일만 그 사람 이름을 붙입니다. 같은 사람일 것 같은 화자는 합치지 않고 묻기만 합니다.
- **받아쓰기 헛소리 줄 흐리게** — "Thank you for watching" 같은 지어낸 줄은 흐리게 보이고 회의록 근거로 쓰지 않습니다.
- **부품 보안 업데이트** — 앱이 쓰는 부품의 알려진 높은·치명 취약점 31건을 고쳤습니다(자동 업데이트 부품 포함).

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.15_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 처음 열 때 막히면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 이미 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.15_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
