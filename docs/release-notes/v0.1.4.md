# 서기 v0.1.4

- 화면을 새로 그렸습니다. 먹색 바탕에 한 줄로 비운 화면이고, 녹음 단추와 오늘 회의만 보입니다.
- 할 일은 '신발장 도면을 다시 그려 보내기'처럼 할 일 꼴로 쓰고, 확인할 곳마다 무엇이 애매한지 적습니다.

## 바뀐 점

- **회의함** — 녹음 단추와 다음 일정이 한 줄에 있고, 아래에 날짜별 회의가 있습니다. 찾기(⌘K), 파일 가져오기, 설정은 오른쪽 위 아이콘에 있습니다. 회의를 한 번 누르면 바로 회의록이 열립니다.
- **회의록** — 할 일 → 이야기 순서로 보이고, 결정·요청·걱정·상담 피드백·이번 회의 정보·받아쓴 글·원본 파일은 '자세히'에 접혀 있습니다. 듣기는 아래 얇은 줄 하나이고, 빨간 눈금이 중요 표시입니다. 이름 없는 말한 사람이 있으면 회의록 맨 위에 바로 한 줄로 알려 줍니다.
- **녹음 중** — 가운데 시계와 회의 이름, 들어오는 소리, 단추 둘(중요 표시, 끝내기)만 있습니다. 고객 이름·참석·현장은 접어 두었고 비워 둬도 됩니다.
- **설정** — 칸마다 무엇을 넣는지 한 줄 설명이 붙었습니다. 드물게 쓰는 것은 맨 아래 '더 보기'에 있습니다.
- **확인할 곳** — '누가 할지 말이 없어요', '금액이나 숫자가 다르게 나왔어요'처럼 무엇이 애매한지 적습니다. 이미 만든 회의록은 그대로 두고, 앞으로 만드는 회의록부터 적용됩니다.
- **글꼴** — 지마켓 산스(SIL 오픈 폰트 라이선스)를 앱에 넣었습니다. 없는 글자는 Pretendard 로 보입니다.
- 시스템이 밝은 모드면 같은 구조의 밝은 화면으로 보입니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.4_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.1 이후 판을 쓰고 있다면 앱 위쪽의 "설치"로 바로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.4_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
