# 서기 v0.1.2

- 회의마다 참석자·현장·메모·회의 단어를 넣어 받아쓰기와 회의록에 함께 씁니다.
- 견적서 PDF·도면·사진에서 이름과 용어를 뽑아 체크만 하면 넣어 줍니다.

## 새로 된 것

- **이번 회의 정보** — 회의록 화면 아래 '이번 회의 정보'에 참석자·현장·메모를 적어 둘 수 있습니다. 녹음하는 동안에도 오른쪽 칸에 적을 수 있고, 캘린더 일정이 있으면 참석자와 장소가 알아서 채워집니다. 늘 쓰는 용어집과 함께 받아쓰기 힌트와 회의록 정리에 씁니다. 적은 뒤 '이 정보로 회의록 다시 쓰기'나 '받아쓰기부터 다시'를 누르면 반영됩니다(원본 녹음은 그대로).
- **자료에서 단어 뽑기** — 회의록 화면에 견적서 PDF·도면·사진을 끌어다 놓거나 '자료에서 단어 뽑기'로 고르면 이름·자재·단지 이름 같은 단어 후보가 나옵니다. 체크만 하면 이 회의에 들어가고, '용어집에도 넣기'를 체크하면 모든 회의에 씁니다. PDF와 글은 어느 방식이든 읽고, 사진은 '내 구독 로그인'(Claude·ChatGPT)으로 정리할 때만 읽습니다.
- **말한 사람 이름 바꾸기** — 받아쓴 글에서 사람 이름을 누르면 참석자와 최근 이름 중에서 고르고(없으면 새 이름), '이 회의 전체 / 여기부터 / 이 줄만' 중 어디에 바꿀지 고릅니다. 회의록에서 그 사람에게 맡긴 할 일의 담당도 함께 바뀝니다.
- **할 일 한 줄** — 할 일이 어디서나 '누가 – 무엇을 – 언제까지' 한 줄로 보입니다. 담당을 모르면 '확인 필요', 기한이 없으면 '미정'으로 표시합니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.2_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.1을 쓰고 있다면 앱 위쪽 검은 띠의 "설치"로 바로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.2_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
