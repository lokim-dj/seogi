# 서기 v0.1.8

- 서기의 새 표시 '기운 타원'으로 앱 아이콘과 메뉴 막대 아이콘이 바뀌었습니다.
- 평소에는 빨간색이 없습니다. 녹음 중이거나 받아쓰기를 듣는 중이면 표시 안에 빨간 점이 1.6초마다 깜빡이고, 회의록을 만들거나 받아쓴 글을 다듬는 동안에는 작고 옅은 점이 보입니다.

## 바뀐 점

- **메뉴 막대** — 평소엔 한 색 표시, 녹음·받아쓰기 중엔 빨간 점이 깜빡이고, 회의록 만드는 중엔 옅은 점.
- **Dock(맥)** — 녹음 중이거나 회의록을 만드는 동안 Dock 아이콘에 점이 보입니다. 회의 내내 눈을 끌지 않도록 Dock 에서는 깜빡이지 않습니다.
- **작업 표시줄(윈도우)** — 작업 표시줄 단추 오른쪽 아래에 같은 점이 겹쳐 보입니다.
- **떠 있는 마이크 단추·받아쓰기 표시** — 새 표시와 점으로 바뀌었습니다. 움직임 줄이기를 켜 두면 점이 멈춰 있습니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.8_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.1 이후 판을 쓰고 있다면 앱 위쪽의 "설치"로 바로 바뀝니다. 바꾼 뒤 Dock 아이콘이 빈칸으로 보이면 서기를 한 번 끄고 다시 켜 주세요.

**Windows (64비트)** — `Seogi_0.1.8_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
