# 서기 v0.1.13

회의록 정리가 멈추지 않게 하고, 첫 화면 일정을 다듬었습니다.

## 바뀐 점

- **회의록 정리가 막히면 다른 방법으로** — 고른 방법(예: API 키)을 쓸 수 없으면, 로그인된 다른 구독(Claude·ChatGPT)이나 저장된 다른 키, 내 컴퓨터 모델로 이어서 정리합니다. 설정은 바꾸지 않습니다. '내 컴퓨터'를 고른 경우에는 밖으로 보내지 않습니다.
- **첫 화면은 내 일정만** — 참석자가 아니거나 거절한 일정은 첫 화면과 시작 알림에서 빠집니다. 오늘 남은 일정이 줄지어 보이고, 줄마다 '이 일정 끄기'로 숨길 수 있습니다. 끈 일정은 설정 › 보관과 일정에서 다시 켭니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.13_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 처음 열 때 막히면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 이미 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바뀝니다. 0.1.12 이후에서 올리면 허락을 다시 할 필요가 없습니다.

**Windows (64비트)** — `Seogi_0.1.13_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
