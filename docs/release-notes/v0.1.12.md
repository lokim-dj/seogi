# 서기 v0.1.12

맥에서 업데이트할 때마다 허락이 풀리던 문제를 고쳤습니다.

## 바뀐 점

- **업데이트해도 허락 유지 (맥)** — 이번 판부터 서기는 판마다 같은 서명으로 만들어집니다. 그래서 다음 업데이트부터는 손쉬운 사용·캘린더·마이크 허락이 풀리지 않습니다. **이번 0.1.12 로 올릴 때만 한 번** 다시 허락해 주세요.
- **허락이 풀리면 알려 줌** — 받아쓰기(손쉬운 사용)나 캘린더 허락이 없으면 첫 화면과 메뉴 막대에 "다시 허락해 주세요"가 뜹니다. 다시 허락하면 서기를 다시 켜지 않아도 바로 살아납니다.
- **소리가 안 들리는 녹음 알림** — 단축키나 일정으로 시작한 녹음이 몇 초 동안 소리를 전혀 못 들으면 한 번 알려 줍니다.
- **녹음 중 참석자** — 녹음 화면의 '참석자, 고객 이름, 현장, 메모' 묶음에서 참석자를 넣고 뺄 수 있습니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.12_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 처음 열 때 막히면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 이미 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.12_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
