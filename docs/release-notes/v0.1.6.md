# 서기 v0.1.6

- 받아쓰기가 생겼습니다. 단축키를 누르고 말하면, 지금 커서가 있는 곳(메일, 메모, 메신저 어디든)에 글자가 들어갑니다. 따로 받아쓰기 앱을 둘 필요가 없습니다.
- 처음에는 꺼져 있습니다. 설정 › 받아쓰기에서 켜세요.

## 바뀐 점

- **받아쓰기** — 기본 단축키는 Control + Option + Space 입니다. 짧게 누르면 켜고 끄기, 길게 누르면 누르는 동안만 듣습니다(설정에서 바꿀 수 있음). 받아쓴 글은 회의함에 남지 않고, 설정의 '최근 받아쓰기'에 마지막 몇 개만 남습니다. 회의를 녹음하는 동안에는 받아쓰기가 쉽니다.
- **글 다듬기** — 켜면 군말을 빼고 띄어쓰기·문장부호를 고치고, 말로 늘어놓은 것은 목록으로 씁니다. 뜻은 바꾸지 않습니다. 내 컴퓨터의 작은 모델(Ollama)이면 1초 안에 끝나고 돈이 들지 않습니다. 구독이나 키로 다듬으면 그 사용량을 쓰고, 다 쓰거나 늦으면 다듬지 않은 글이 그대로 들어갑니다.
- **떠 있는 마이크 단추** — 켜면 다른 앱 위에 작은 단추가 뜹니다. 누르면 듣고, 다시 누르면 글자가 들어갑니다. 끌어서 옮길 수 있고, 오른쪽 클릭으로 숨깁니다.
- **말하는 동안 표시** — 화면 아래 가운데에 '듣는 중', '다듬는 중'이 작게 보입니다.
- **맥 권한** — 다른 앱에 글자를 넣으려면 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 '서기'를 켜야 합니다. 설정 화면이 안내합니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.6_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.1 이후 판을 쓰고 있다면 앱 위쪽의 "설치"로 바로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.6_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
