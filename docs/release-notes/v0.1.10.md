# 서기 v0.1.10

처음 설치하는 날 막히지 않게 다듬었습니다. 받아쓰기와 회의록도 더 깔끔해졌습니다.

## 바뀐 점

- **처음 실행 안내** — 서기가 쓰는 권한(마이크, 손쉬운 사용, 캘린더, 알림)을 한 화면에서 차례로 허락할 수 있습니다. 같은 줄 묶음이 설정에도 있습니다.
- **컴퓨터를 켜면 서기도 켜기** — 처음부터 켜져 있고, 설정 › 시작에서 끌 수 있습니다. 스위치는 시스템의 실제 등록 상태를 보여 줍니다.
- **받아쓰기** — 처음부터 켜져 있습니다. 어느 앱에서든 ⌥Space(윈도우는 Alt + Space)를 누르고 말하면 글자가 들어갑니다. 언어는 한국어로 고정해 다른 나라 글자로 잘못 적히지 않게 했고, 기본 모델은 빠르고 영어 섞인 말도 잘 받는 Fun-ASR Nano 입니다. 처음 실행 때 함께 내려받습니다.
- **숫자는 숫자로** — 받아쓰기에서 "이십 초", "삼천오백 원", "오후 세 시 반"을 "20초", "3,500원", "오후 3시 반"으로 적습니다. 헷갈리는 말은 그대로 둡니다. 설정에서 끌 수 있습니다.
- **최근 받아쓰기 지우기** — 한 줄씩 지우거나 모두 지울 수 있습니다.
- **검색에서 그 줄로** — 회의함 검색 결과에 찾은 말이 든 줄이 보이고, 누르면 회의록의 그 자리로 가서 노란 형광펜으로 표시합니다. 다른 곳을 누르면 풀립니다.
- **할 일 목록** — 묶음 제목이 이미 누구 숙제인지 말하므로, 줄마다 겹쳐 붙던 담당과 문장 앞 주어를 걷었습니다. 담당이 정해지지 않은 일은 '담당 미정'으로 보입니다.
- **구독으로 로그인** — 회의록 정리를 Claude 나 ChatGPT 구독으로 맡길 때, 설정과 처음 실행 화면에서 [로그인] 단추로 바로 로그인할 수 있습니다. 필요한 도구가 없으면 공식 설치 안내로 이어 줍니다.
- **API 키** — 키를 넣기 전에는 '키가 필요해요'로 보이고, 모델 목록을 지금 모델로 바꿨습니다.

## 설치

**macOS (Apple Silicon)** — `Seogi_0.1.10_aarch64.dmg`를 열어 응용 프로그램 폴더로 옮깁니다. 서명되지 않은 앱이라 처음 열 때 막힙니다. 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요. 0.1.9 를 쓰고 있다면 앱 위쪽의 "새 버전 설치"로 바로 바뀝니다.

**Windows (64비트)** — `Seogi_0.1.10_x64-setup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" › "실행"을 누르세요.

`*.sig`, `*.app.tar.gz`, `latest.json`은 앱이 스스로 업데이트할 때 쓰는 파일입니다. 직접 받을 필요는 없습니다.
