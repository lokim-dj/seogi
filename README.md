# 서기 (Seogi)

기록이 필요한 자리에서 대신 받아 적고 정리해 주고, **내가 해야 할 일부터** 알려 주는 서기 앱입니다. 회의를 녹음하면 누가 무슨 말을 했는지 받아 적고, 할 일부터 정리한 회의록을 만들어 줍니다. macOS와 Windows에서 돌아가고, 녹음과 받아쓰기는 내 컴퓨터 안에서 처리됩니다.

> 혼자 쓰려고 시작했지만, 여러 사람이 쓰면서 함께 고쳐 나가면 더 좋은 앱이 될 거라고 생각합니다. 불편한 점과 바라는 점은 [GitHub 이슈](https://github.com/lokim-dj/seogi/issues)에 남겨 주세요.
>
> 지금은 개발 중입니다. 되는 것과 아직 안 되는 것은 아래 [지금 상태](#지금-상태)에 그대로 적어 둡니다.

## 무엇을 하나요

- **앱에서 바로 녹음** — 버튼 하나로 시작하고 끝냅니다. 긴 회의도 조각조각 디스크에 바로 써서, 앱이 꺼지거나 노트북이 잠들어도 녹음이 사라지지 않습니다. 녹음 중 "중요 표시"를 누르면 그 시각이 회의록에 반영됩니다.
- **녹음함 폴더 지켜보기** — 휴대폰 녹음기가 올려 주는 폴더(구글 드라이브 등)를 한 번 정해 두면, 새 녹음 파일이 들어올 때마다 알아서 처리합니다.
- **옛 녹음 가져오기** — m4a, mp3, wav, aac, 3gp, amr 등.
- **화자 구분 받아쓰기** — 한국어에 맞춘 음성 인식. 내 용어집(사람 이름·현장 이름·전문 용어)을 녹음의 모든 구간에 적용합니다.
- **회의록** — 한 줄 요약 → 액션 아이템(할 일 · 담당 · 기한 · 근거 시각) → 결정 사항 → 핵심 논의 → 확인 필요. 회의록 틀은 고칠 수 있는 데이터입니다.
- **원본 보존** — 원본 녹음은 고치지도 지우지도 않고, SHA-256과 녹음 시각을 함께 남깁니다. 회의록의 모든 줄은 원본의 시각으로 되짚을 수 있습니다.
- **내 AI 골라 쓰기** — 기본은 전부 내 컴퓨터(무료). 원하면 내 계정의 AI를 받아쓰기와 요약에 따로 연결할 수 있습니다.

### 정확도 (연습용 합성 녹음 기준)

실제 회의가 아니라, 대본을 컴퓨터 목소리로 읽혀 만든 3~4분짜리 녹음 8~12개로 잰 값입니다(`eval/`). 속도는 녹음마다 다릅니다: 아래 실제 회의에서는 Qwen3 가 turbo 보다 조금 느렸습니다. 실제 회의에서는 이보다 낮게 나옵니다.

| 받아쓰기 모델          | 글자 오류율                                                    | 속도                |
| ---------------------- | -------------------------------------------------------------- | ------------------- |
| Qwen3-ASR-1.7B (기본)  | 용어집을 쓰면 2.3 % (12개 기준. 같은 12개에서 turbo는 2.1 %)   | 녹음 길이의 약 1/12 |
| whisper-large-v3-turbo | 용어집 없이 2.6 % → 용어집을 쓰면 1.8 %                        | 녹음 길이의 약 1/9  |
| whisper-large-v3       | 용어집을 쓰면 1.8 % (wav 4개 기준. 같은 4개에서 turbo는 1.7 %) | 약 1/6              |

- 합성 녹음에서는 turbo 가 조금 낫지만, 실제 회의 녹음(1시간 50분, 다른 녹음기의 전사를 기준으로 잼)에서는 Qwen3-ASR-1.7B 가 가장 적게 틀렸습니다: 노트북 마이크 녹음에서 글자 오류 17.1 %(turbo 17.6 %, Fun-ASR Nano 20.5 %). turbo 가 다른 나라 말로 잘못 적은 줄 31개가 Qwen3 에서는 없었습니다. 그래서 기본은 Qwen3-ASR-1.7B 입니다. 그 녹음을 받아쓰는 데는 8.2분(turbo 7.8분)이 걸렸습니다.
- 용어집에 넣은 말을 맞게 적은 비율은 77 % → 94 %로 올라갑니다.
- 화자 구분 정확도는 86 %입니다. 한 목소리를 변조해 만든 화자들이라 실제와 다를 수 있습니다.
- 회의록은 항목마다 근거 인용을 받아쓴 글과 대조해, 맞는 것만 싣고 의심스러운 것은 "확인 필요"로 보냅니다.

## 쓰는 법 (개발 중인 지금)

1. 처음 켜면 회의록 정리를 어디에 맡길지, 캘린더와 녹음함 폴더를 정하는 화면이 나옵니다. 받아쓰기 모델(2.2 GB)과 화자 구분 모델은 그때 한 번 내려받습니다.
2. 회의록을 쓸 모델을 하나 준비합니다.
   - 무료, 내 컴퓨터: [Ollama](https://ollama.com/)를 깔고 `ollama pull gemma3:12b` (8 GB). 3분 녹음에 5분쯤 걸립니다.
   - 내 계정: Claude Code(`claude`)나 Codex(`codex`)에 로그인되어 있으면 그것을 쓸 수 있습니다. 1분쯤 걸립니다.
3. "녹음 시작"을 누르거나, 녹음 파일을 창에 끌어다 놓거나, 폴더를 지켜보게 합니다. 나머지는 알아서 진행되고, 끝나면 알림이 한 번 옵니다.

### 처음 켤 때 macOS가 묻는 것

서명하지 않은 미리보기라 macOS가 몇 가지를 직접 묻습니다. 모두 한 번만 묻습니다.

| 언제                                  | 묻는 말                                                     | 누를 것                                             |
| ------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| 앱을 처음 열 때 (내려받은 dmg인 경우) | 확인되지 않은 개발자의 앱                                   | 시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기" |
| 처음 실행 화면에서 녹음함을 찾을 때   | "서기"가 Google Drive에서 관리하는 파일에 접근하려고 합니다 | 허용                                                |
| 처음 녹음을 시작할 때                 | "서기"가 마이크에 접근하려고 합니다                         | 허용                                                |
| 회의를 처음 보관할 때                 | "서기"가 문서 폴더의 파일에 접근하려고 합니다               | 허용                                                |

마이크를 허용하지 않았다면 시스템 설정 › 개인정보 보호 및 보안 › 마이크에서 서기를 켜면 됩니다.

회의마다 `문서/서기/2026-11-24 1400 제목/` 폴더가 생기고 그 안에 원본 녹음, `회의록.md`, `전사.txt`, `원본정보.json`이 들어갑니다.

### 내 용어집

사람 이름, 현장 이름, 전문 용어를 적어 두면 받아쓸 때 모든 구간에 힌트로 쓰입니다. 앱의 데이터 폴더에 `vocabulary.txt`를 두거나 설정에서 다른 파일 · 폴더를 가리키면 됩니다. 용어집은 내 컴퓨터에만 있고 이 저장소에는 들어가지 않습니다.

```text
# 한 줄에 하나씩
걸레받이
한빛아파트
# 틀린 말 => 바른 말
걸래받이 => 걸레받이
```

## 개발

필요한 것: [Rust](https://rustup.rs/)(stable), [Bun](https://bun.sh/), CMake. 자세한 준비물은 [BUILD.md](BUILD.md)에 있습니다.

```bash
bun install
bun run tauri dev      # 개발 실행
bun run tauri build    # 설치 파일 만들기
```

창 없이 전체 흐름을 돌려 볼 수도 있습니다(내 설정과 보관 폴더는 건드리지 않습니다).

```bash
seogi --seogi-library ./lib --seogi-import meeting.m4a --seogi-llm ollama:gemma3:12b
seogi --seogi-library ./lib --seogi-watch ./inbox
python3 eval/synthetic/make_clips.py && python3 eval/run.py   # 정확도 재기
```

## English

Seogi ("the one who takes the minutes") is a desktop meeting secretary for macOS and Windows. Record a meeting, or drop in a recording, and it produces a speaker-separated Korean transcript and minutes that lead with the action items. Audio is transcribed on your own computer; the original recording is never altered. The project is under development and not yet released.
