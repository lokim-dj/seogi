# Seogi's words

The words Seogi uses for its own things, on screen and in code. One word per thing. This is not the user's 용어집 (their personal vocabulary for transcription), which never enters this repository.

No implementation detail here: what a thing is, not how it works. A new screen text, type or file name uses these words; a word in _Avoid_ is not used for that thing.

## Things

**회의** (`Meeting`):
One recording and everything made from it, kept together in one folder.
_Avoid_: 세션, 기록물, 노트

**원본** (the original recording):
The recording file exactly as it was recorded or brought in. Never changed.
_Avoid_: 소스, 원음

**받아쓴 글** (`transcript`, `전사.txt`):
What was said, by whom and when.
_Avoid_: 스크립트, 자막

**회의록** (`Minutes`, `회의록.md`):
The write-up of a meeting: tasks first, then the story, then the rest.
_Avoid_: 요약본, 리포트

**할 일** (an action item):
Something someone has to do after the meeting, with who and by when if it was said.
_Avoid_: 태스크, 투두

**확인 필요**:
A line the machine could not fully support from the transcript, shown for the person to check by ear.
_Avoid_: 경고, 오류

**시각** (the timestamp key):
Where in the original a line comes from. Pressing it plays that moment.

**중요 표시** (a mark):
A moment the person flagged while recording.

**회의함** (`Library`):
All the meetings, and the folder on disk that holds them.
_Avoid_: 보관함, 목록

**녹음함** (a watched folder):
A folder Seogi watches for new recordings, such as the one a phone uploads to.
_Avoid_: 인박스, 동기화 폴더

**용어집** (`Vocabulary`):
The user's own names and terms, used as hints when transcribing every meeting.

**회의 단어**:
Names and terms for one meeting only.

**회의 종류** (`Template`):
A kind of meeting and the shape of its minutes. Data, not code.

**배너** (`banner`):
The small always-on-top window: a meeting is starting, minutes are ready.

**말로 입력** (`dictation`):
Seogi's second job: a shortcut, a few words spoken, and the words typed where the cursor is. Nothing of it goes to the 회의함. Turning a recording into text keeps 받아쓰기.
_Avoid_: 받아쓰기, 음성 입력 (for this feature)

**마이크 단추**:
The phone app's floating key for 말로 입력 (planned). The computer has none: the shortcut is enough there.

## Words still to settle

The maintainer picks; until then, keep each pair as it is and do not add a third word.

- **액션 아이템** (README) and **할 일** (screens) are the same thing. Pick one for public text.
- **전사** (file name `전사.txt`) and **받아쓴 글** (screens) are the same thing. The file name stays, since people already have it on disk; say which word prose uses.
- **회의록 틀** (README) and **회의 종류** (screens) are the same thing. Pick one.
